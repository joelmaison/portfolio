# Joel Maison — Portfolio

Personal portfolio for Joel Maison, focused on Data, AI, Analytics, and selected Sports Analytics work.

## Structure

- `index.html` — main professional portfolio
- `sports.html` — dedicated sports analytics and basketball page
- `styles.css` — shared design system and responsive styles
- `data.js` — project and community content
- `app.js` — rendering, filters, and interactions

The site is intentionally data-driven so new projects can be added by editing `data.js` instead of rebuilding the layout.

## Run locally

Open `index.html` directly, or use VS Code Live Server.

## Deployment

Designed to deploy cleanly on Vercel as a static site.
